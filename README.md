# Test Utòpic de Poti · v0.12

## Novetats
- Afegeix una síntesi personal global que connecta les tres dimensions.
- Dona un nom interpretatiu a cada dimensió (política, realitat i coneixement, existència i ètica) i n’explica les principals inclinacions.
- Les conclusions utilitzen les etiquetes de les respostes, indiquen quantes preguntes s’han contestat i es marquen com a provisionals quan hi ha poques respostes.
- La síntesi i les conclusions de dimensió s’inclouen també en el text compartit.
- Interfície i textos disponibles en català, castellà i anglès.
- Manté les 33 preguntes, el catàleg ampliat, els perfils de pensadors, els filtres i el disseny de la v0.11.

## Nota de rigor
Les denominacions són aproximacions interpretatives, no identitats fixes ni diagnòstics. En política, el perfil evita usar “feixisme socialista” com una etiqueta única: quan les respostes ho indiquen, diferencia nacionalisme autoritari, ultranacionalisme i corporativisme estatal.

## Publicar
Substitueix els fitxers del directori arrel del repositori pels d’aquest paquet, mantenint els noms: `index.html`, `pensadores_catalogo.json`, `icon-192.png`, `icon-512.png` i `manifest.webmanifest`. No cal canviar el nom del repositori ni la configuració de Pages.

El test és una eina filosòfica exploratòria i no una prova psicomètrica validada.
